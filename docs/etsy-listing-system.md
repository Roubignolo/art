# Système de listing Etsy — standard "hyper pro"

> Marque d'édition d'art à la demande, **domaine public curé** (œuvres CC0 restaurées) — POSTER / ENCADRÉ / TOILE + giftables, production **Gelato** (défaut) + **Prodigi** (premium).
> Ce document = (1) best practices Etsy 2026 sourcées, (2) anatomie reproductible du listing, (3) matrice variantes × prix, (4) exemple travaillé complet sur une vraie œuvre Van Gogh CC0 du Met.

> ⚠️ **Règle dure marque** : attribution Etsy **« sourced by »**, jamais « made by ». Provenance documentée par œuvre. Aucune œuvre produite sans validation humaine des gates DP/marque.

| **Style** | L'algo 2026 favorise les **phrases naturelles et lisibles** plutôt que les listes de mots-clés empilés. | [ListingForge — Title Formula](https://www.listing-forge.com/blog/etsy-title-formula), [Etsy Seller Handbook](https://www.etsy.com/seller-handbook/article/1399426136697) |

## 2. Anatomie du listing type (template réutilisable)

### 2.1 Titre

**Règle** : mot-clé primaire (`Artiste + Titre œuvre`) dans les 40 premiers caractères ; ≤ 140 car., viser 70–120 ; phrase lisible ; pas de bourrage.

**Gabarit** :
```
[Artiste] [Titre de l'œuvre] | [Type produit + format] | [Style/époque] | [Usage/pièce] | [angle cadeau]
```
Ordre = du plus recherché (gauche) au plus secondaire (droite). Le premier bloc avant le 1er `|` doit suffire à comprendre l'annonce sur mobile.

### 2.2 Les 13 tags — gabarit de répartition

| # | Catégorie de tag | Exemple de slot | Type |
|---|---|---|---|
| 1 | Artiste | `van gogh print` | générique fort |
| 2 | Œuvre / sujet précis | `wheat field cypresses` | longue traîne |
| 3 | Type produit + format | `large wall art print` | générique fort |
| 4 | Mouvement / style | `post impressionism art` | longue traîne |
| 5 | Médium / look | `fine art poster` | longue traîne |
| 6 | Pièce / room | `living room wall art` | intention |
| 7 | Pièce / room 2 | `bedroom decor print` | intention |
| 8 | Format / orientation | `landscape art print` | longue traîne |
| 9 | Niche déco | `vintage wall decor` | longue traîne |
| 10 | Couleur / palette | `yellow blue wall art` | longue traîne |
| 11 | Occasion / cadeau | `art lover gift` | intention cadeau |
| 12 | Encadré / canvas | `framed canvas art` | variante produit |
| 13 | Marque/positionnement | `museum art print` | différenciation |

Règles : aucun tag dupliqué en racine, phrases > mots seuls, ≤ 20 car./tag, mélange volume + longue traîne.

### 2.3 Description structurée (squelette)

Etsy indexe désormais davantage la description (et Google la lit). Structure recommandée, par sections :

```
[1. ACCROCHE PROVENANCE] (2-3 lignes)
   — Le nom de l'œuvre, l'artiste, l'année, l'institution source CC0. Le "pourquoi cette œuvre".

[2. CONTEXTE HISTORIQUE] (3-5 lignes)
   — Mini récit : où/quand peinte, anecdote vérifiable, ce qu'elle représente.
   — RÈGLE : aucun fait inventé. Sourcer (Met / Wikidata).

[3. SPECS PRODUIT]
   — Papier (museum-quality matte 250 gsm), encres pigmentaires, finitions cadre,
     toile galerie ; production locale (UE/FR via Gelato).

[4. VARIANTES & TAILLES]
   — Liste tailles (A4/A3/A2/50×70) × options (nu / encadré chêne-noir-blanc / toile).
   — Tableau de correspondance cm ↔ pouces.

[5. EXPÉDITION]
   — Délais (3-5 j FR/UE), suivi, emballage protégé (tube/carton rigide), dropshipping direct.

[6. ATTRIBUTION « SOURCED BY »]  ← OBLIGATOIRE
   — « Œuvre du domaine public, sourcée et restaurée par [marque]. Nous ne revendiquons
     aucun droit sur l'œuvre originale ; nous vendons la curation, la restauration et la confiance. »
   — Provenance : institution + n° d'accession + statut DP.

[7. ENTRETIEN]
   — Éviter soleil direct prolongé, dépoussiérer à sec, etc.

[8. FAQ / RÉASSURANCE] (optionnel)
   — Cadeau, délais, contact.
```

### 2.4 Attributs Etsy à remplir (wall art)

- **Catégorie** : Home & Living > Home Decor > Wall Decor > Prints
- **Orientation** : Paysage / Portrait (selon œuvre)
- **Couleur primaire / secondaire** : renseigner les 2 dominantes
- **Style** : ex. *Fine Art*, *Vintage*, *Country/Rustic* selon œuvre
- **Matériau** (par variation) : papier / cadre bois / toile
- **Occasion / Holiday** : laisser vide sauf œuvre réellement thématique
- **Made by / Sourced** : la marque opère en **« sourced by »** (mention en description + politiques boutique)

## 3. Matrice variantes × prix (œuvre type, production Gelato)

### 3.1 Formule de pricing

```
Prix de vente conseillé = arrondi.psycho( Coût_base_Gelato × Markup )
Marge nette € = Prix − Coût_base − Coût_port − Frais_Etsy − Provision_SAV
  où  Frais_Etsy   = Prix × 11 %  (6,5 % transaction + 4 % paiement + 0,47 % régl.) + 0,47 € fixes (0,30 € + 0,17 €)
      Provision_SAV = Prix × 5 %
      Coût_port     = intégré dans la base ci-dessous (livraison "gratuite" → meilleur ranking, cf. §1.4)
Markup cible : ×3,2 à ×3,6 sur poster nu ; ×2,2 à ×2,6 sur encadré/toile (base plus élevée).
```

> ⚠️ **Coûts base Gelato = à confirmer via Gelato API.** La recherche web 2026 ne publie pas le tarif exact par taille/cadre ; fourchette publique constatée : ~5 $ (petit tirage) → ~24 $ (grand encadré) ([PrintOnDemandBusiness — Gelato review](https://www.printondemandbusiness.com/blog/gelato-print-on-demand-a-comprehensive-review/)). Les valeurs ci-dessous combinent cette fourchette + les fourchettes du brief (A2 nu 8-11 €, A2 encadré 32-40 €). **À recaler avant mise en vente.**
